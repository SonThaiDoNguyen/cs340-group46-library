# cs340-group46-library
CS340 Portfolio Project – Group 46

This project implements a library management system that manages books, authors, genres, patrons, book copies, and loans.

The base application structure was adapted from the CS340 starter code provided in the course.

The database schema design, UI implementation, and CRUD routes were developed by the project team.

AI tools (ChatGPT) were occasionally used to help debug syntax errors during development.
